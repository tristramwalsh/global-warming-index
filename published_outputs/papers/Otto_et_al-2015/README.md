# Otto et al. (2015): original Global Warming Index spreadsheet

The spreadsheet version of the original GWI calculation, from Otto et al.
(2015).
- It predates the Python code in this repository, and does not run with it.
- Kept for the record. It was added to the repository in 2022, and moved here
  from `data/observed-2014-legacy-xlsx/` in November 2026.
